# 记忆系统测试评估



验证Agent记忆插件的效果，需要从 **“存得准”**、**“查得全”** 和 **“用得对”** 三个维度，结合自动化断言与人工基准评估进行测试







1. 黄金测试集设计（Golden Dataset）

你可以直接将以下多轮对话序列输入给你的 Agent，用来测试插件的记忆提取、更新和召回能力。

| 轮次      | 用户输入（测试动作）                                                           | 预期插件行为 / 记忆库变化                                                                                              |
| ------- | -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **第一轮** | “你好，我叫李明，目前手头有 50 万闲置资金，风险偏好是稳健型。我想配置点白马股，比如贵州茅台，但持仓绝对不能超过总资产的 10%。” | **【新增隐式/显式记忆】**<br>• 用户姓名：李明<br>• 风险偏好：稳健型<br>• 可投资金额：50万<br>• 核心偏好：白马股（如贵州茅台）<br>• 硬性风控：单一股票持仓 ≤ 10%（5万）   |
| **第二轮** | （隔天或更换会话）<br>“帮我分析一下贵州茅台现在的估值，我想买 8 万元的。”                            | **【触发风控拦截/记忆召回】**<br>Agent 必须检索出“单一持仓 ≤ 10%”的记忆，并主动提醒：“李总，您之前提到茅台持仓不能超过总资产的 10%（即 5 万元），买入 8 万元将超标，是否确认调整？” |
| **第三轮** | “哦对，看我这记性。那改一下，把风控线提高到 20% 吧，茅台买 8 万。”                               | **【记忆更新与冲突解决】**<br>插件必须**覆盖/更新**旧记忆：<br>• 单一股票持仓上限由 10% 更新为 20%。                                            |
| **第四轮** | （一周后）<br>“帮我看看我的资产配置，目前还剩多少风控额度？”                                    | **【多变量复合检索】**<br>Agent 需结合总额（50万）、已用（8万）和新风控线（20% = 10万）计算，回答：“您目前茅台持仓 8 万，距离 20% 的新风控线（10万）还剩 2 万元额度。”     |



2. 财经场景核心验证维度

针对上述样例，你需要重点验证插件的以下三个财经专属能力：

🔍 实体与数值的绝对精确度（Entity & Numerical Precision）

- **测试点**：财经领域的“50万”和“5万”失之毫厘谬以千里。
- **验证方法**：检查插件存入数据库的 Payload（数据载荷）。确保数字没有被 LLM 模糊化（如变成“几十万”），且单位（万、元、%）没有丢失。

🔄 动态策略更新（Dynamic Policy Overriding）

- **测试点**：用户的投资理念和风控偏好是动态变化的（如第三轮中风控线从 10% 变 20%）。
- **验证方法**：输入第三轮指令后，去数据库查询该用户的 `risk_control_limit` 字段，确认旧的 "10%" 是否已被标记为“过期/历史版本”，而新的 "20%" 成为 Active（激活）状态。防止 Agent 出现记忆混乱。

🧠 隐式意图转化为显式记忆（Implicit Memory Extraction）

- **测试点**：用户常说隐语。例如用户说：“我不喜欢高波动，科技股太刺激了。”
- **验证方法**：测试插件能否自动提炼出隐式记忆：`{"不喜欢": ["高波动", "科技股"], "风险偏好": "保守/稳健"}`，而不需要用户死板地说“我的风险偏好是稳健型”。

3. 自动化断言脚本示例 (Python 伪代码)

你可以写一个简单的测试脚本来自动化验证插件的读写：

python

```
def test_finance_memory_plugin():    # 1. 模拟第一轮写入
    agent.chat("我叫李明，有50万资金，茅台持仓不能超过10%")        # 断言：记忆库中成功提取了风控线
    memory = memory_plugin.get_memory(user_id="李明", key="risk_control")    assert memory["threshold"] == 0.10, "风控阈值记忆错误！"
        # 2. 模拟第二轮触发
    response = agent.chat("我想买8万块的茅台")        # 断言：Agent的回复中必须包含风控警告关键词
    assert "超过" in response or "10%" in response, "Agent未能成功召回风控记忆进行拦截！"
```
